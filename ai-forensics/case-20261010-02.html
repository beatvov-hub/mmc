Gemini Code Assistの新規販売終了、契約別の更新期限を確認する

Google Cloudは2026年10月9日、Gemini Code Assist StandardとEnterpriseの新規購入を終了しました。既存契約は契約期間の終わりまで利用・サポートが続きますが、ライセンス追加と年契約の自動更新は2027年1月31日まで、月契約の自動更新は2027年12月31日までです。契約終了日と更新種別によって余裕が異なるため、管理者は契約情報を確認し、代替として案内されているAntigravityを含めて移行計画を立てます。

  • IDE向けAIコーディング支援の契約更新を管理する人

危険度ではなく、必要な確認の程度を表しています。

新規購入は終了しましたが、既存契約は契約期間まで継続します。ライセンス追加・更新期限を契約の種類ごとに確認してください。

Step 1

身近な事例を知る

会社のGemini Code Assistが買えなくなると聞き、いまの契約も止まるのか確認したい

新規販売終了という告知を見て、現在のライセンスが急に無効になるのか、いつまでに移行すべきか分かりません。

なぜ確認が必要？

新規購入終了、既存契約の有効期間、ライセンス追加、更新停止は別の日程で進みます。契約の種類を確かめてから代替製品の移行を準備できます。

Step 2

あなたならどうする？

Gemini Code Assist Standard／Enterpriseの利用者がまず確認することは？

まず一つ以上選んでから確認してみてください。

推奨される行動
  • 契約終了日と年契約・月契約の別を確認し、追加・更新期限に合わせて移行を計画する

選んだカードの表示を見ながら、今回はどの行動が安心につながるか確認できます。

新規購入終了は既存利用の即時終了ではありません。追加ライセンス、年更新、月更新の期限と各組織の契約終了日を個別に確認してください。

Step 3

確認ポイント

優先して確認

新規購入は2026年10月9日に終了

この日以降、Gemini Code Assist StandardとEnterpriseの新しい契約は購入できません。

優先して確認

既存契約は契約期間まで継続

現在の契約は契約上の終了日まで使え、サポートも続くとGoogleは説明しています。購入終了とサービス即時停止は別です。

優先して確認

追加ライセンス期限

既存契約への新しいライセンス追加は2027年1月31日までです。その後は新規ライセンスを追加できません。

優先して確認

年契約・月契約で自動更新の期限が異なる

年契約の自動更新は2027年1月31日まで、月契約の自動更新は2027年12月31日までと案内されています。契約種別と日付を確認します。

できれば確認

代替製品の利用条件

GoogleはAntigravityを今後のエージェント型開発支援として案内し、Gemini Enterpriseの対象エディションなどを経由する利用条件を示しています。既存契約と同条件で移行できるとは限らないため、契約・機能・データ条件を別に比べます。

Step 4

現時点での見立て

確度は高めGemini Code Assistは新規販売終了。既存契約は契約期限まで利用可能

契約別の追加・更新期限を確認し、終了前に移行先と必要な機能を検討します。

Step 5

安全な対処方法

安心につながる行動

  • Google Cloudの請求・契約画面でStandard／Enterpriseの契約終了日を確認する既存契約の利用終了日は各契約期間に基づきます。
  • 年契約か月契約か、ライセンス追加が必要かを確認する追加・更新可能な期限が契約形態によって異なります。
  • 移行先Antigravityの対象契約・IDE対応・運用条件を管理者と照合する代替製品の契約・運用条件が現状と同じとは限りません。

避けたい行動

  • 販売終了の日付を既存サービスの停止日として社内へ伝える既存契約は契約期間終了まで継続します。
  • 期限直前までライセンス追加や移行検証を先送りする追加と年更新の期限は月契約の更新期限より早く設定されています。
Step 6

AIの前向きな活用

契約形態に沿って移行時期を決める

購入終了、追加期限、更新期限、契約満了を分けて一覧化すると、開発チームの利用を段階的に移せます。

  • 契約期限を台帳へ記録
  • 必要ライセンス数を確認
  • 代替環境でIDEと権限を検証

誠主任からひとこと

『販売終了』の一語だけでは、明日使えなくなるように受け取られがちです。Googleの案内は追加ライセンスと年・月更新で締切が違うので、契約台帳に日付を落とす実務がいちばん大切です。

今回、覚えておきたいこと

Gemini Code Assistの契約は、新規購入・追加・更新・契約満了の期限を分けて移行を計画する。

WindowsのAIエージェント、ローカル実行とクラウド実行をどう確認する？
