# Halloween 2026 イベント下書き

2026年10月31日のラウンジ会話を蓄積する、ローカル下書きページです。

- ページ：`lounge/events/halloween-2026/index.html`
- 元データ：`src/data/eventDrafts/halloween-2026.json`
- 生成：`python -B scripts/generate_halloween_event.py`
- スタイル：`lounge/events/halloween-2026/event.css`
- 画像：`image/events/halloween-2026/`（採用済み所長V2を含む既存WebP 18点＋会話場面7点）

## 公開状態

現在は `status: "draft"`。HTMLに `noindex, nofollow, noarchive` を付け、公開イベントデータ `src/data/events.json` には登録していません。トップ・ラウンジ・イベント一覧・サイトマップからのリンクもありません。今回はコミット・プッシュ・デプロイをしません。

`noindex` はアクセス制限ではありません。将来ホスティングへ載せる場合は、URLを知る人が閲覧できる状態になります。

既存の `generate_events.py` が整理するのは `lounge/events/` 直下のHTMLです。この下書きはサブフォルダ内にあるため、既存イベントの再生成で削除されません。専用ジェネレーターもイベント一覧・サイトマップ・リダイレクトを書き換えません。

## 追記データの形式

記入方法の例です。下の文章は実際の会話としてページへ出していません。

```json
{
  "id": "section-13",
  "title": "ここに受け取った場面タイトル",
  "blocks": [
    {"type": "heading", "text": "必要な場合だけ、受け取った小見出し"},
    {"type": "narration", "text": "受け取った地の文。"},
    {"type": "dialogue", "speaker": "ほのちゃん", "speakerDetail": "STARLINE／宇宙飛行士", "text": "受け取った発言。\n改行も使用できます。"},
    {"type": "dialogue", "speaker": "所長よっしー", "text": "受け取った発言。"},
    {"type": "whiteboard", "text": "ホワイトボードに残った言葉。"},
    {
      "type": "image",
      "src": "image/events/halloween-2026/dango-showcase.webp",
      "alt": "団子姿の所長を囲む社員たちとペチ",
      "caption": "場面に合う説明。"
    }
  ]
}
```

- `id` はページ内で重複しない半角英数字・ハイフン。アンカーは `#section-13` になります。
- 時刻が示されている場合だけ `time`（例 `18:00`）と、必要に応じて `timeLabel` を追加します。時刻不明なら省略し、推測で付けません。
- 発言者は13名の名前に合わせます。所長は「所長よっしー」「所長」「よっしー」に対応。
- 会話は平文で保存。HTMLは文字としてエスケープされます。
- 新しい発言・出来事を補作せず、所長から渡された内容を追記します。
- 仮装・作品の補足は `speakerDetail` に保持し、本文とともにHTMLとしてエスケープします。
- 発言者名の横の絵文字は `speakerEmoji` に保持します。縦長画像を本文に入れる際は画像ブロックへ `portrait: true` を付け、正しい縦横比・最大幅420pxで表示します。
- 会話途中の小見出しは `type: "heading"` で保持し、場面タイトルH3の下のH4として出力します。
- 場面が複数になったときだけ、場面名の目次を表示します。番号や件数は表示しません。`partyPhotos` は利用可能な画像の一覧で、独立したギャラリーとしては重複表示しません。

```powershell
python -B scripts/generate_halloween_event.py
python -B -m unittest tests.test_halloween_event
```

`generate_lounge.py` の全件実行は不要です。既存ラウンジログ・過去イベントは編集しません。

## 公開する時

所長の掲載指示を受けてから本文・実際の時刻・画像説明を確認し、イベント一覧登録、正規URL、リダイレクト、canonical、サイトマップ、noindex解除を一緒に整えます。専用ジェネレーターは `status: "draft"` 以外を拒否するため、日付が10月31日になっただけで公開へ切り替わることはありません。
