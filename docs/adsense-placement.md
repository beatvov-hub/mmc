# AdSense 手動広告の設定

初期状態では `src/data/adsense-config.json` の `enabled` と各グループはすべて `false` で、広告ユニットを生成しません。既存のGoogleコードと忍者AdMaxはこの設定とは別です。

承認後、AdSense管理画面で正式に発行した広告ユニットのスロットIDを該当グループの `slot` に文字列で入力し、対象グループと全体の `enabled` を `true` にします。`learning` はAI学習室トップだけの追加候補で、最初は無効です。IDが空・不正の場合は表示しません。対象は `src/data/adsense-routes.json` の完全一致URLだけです。404、一覧、クイズ詳細、ゲーム等に前方一致で拡大しません。

制作物や鑑識室の記事を追加・公開した後、`python -B scripts/update_adsense_routes.py` で一覧を更新し差分を確認してください。`--check` で生成データとの一致を検証できます。データにない新URLは更新するまで広告対象にならないため、安全側に倒れます。

自動広告はこの手動ユニットの設定では制御できません。AdSense管理画面の「広告」→対象サイトの編集→「広告設定」→「自動広告」をオフにし、「サイトに適用」して保存してください。設定の現在値は管理画面で確認が必要です。審査が承認されるまでは有効化しないでください。承認後も実際の配信、表示速度、未配信時の余白、スマートフォンでの誤タップ、プライバシーポリシーの内容を確認してください。
