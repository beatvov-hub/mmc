Joplin Web Clipper

公式サイトを見る ↗（外部サイト）

For Whom

こんな人向け

海外調査や広報で、参照したWeb資料がブラウザーのタブに埋もれ、記事や企画を書くときに出典を探し直している人向けです。公開ページを調査ノートとして手元に集めたい場合に役立ちます。

The Answer

結論

Joplin Web Clipperは、ブラウザーで開いたWebページやスクリーンショットをJoplinのノートとして保存できる拡張機能です。保存にはJoplinデスクトップアプリが必要で、端末間の同期は別設定です。

How to Use

やり方／確認方法

例えば、海外調査の公開公式資料を後から参照する想定例です。PCにJoplinデスクトップアプリと対応ブラウザーのWeb Clipper拡張を用意し、アプリの設定にあるWeb Clipper項目の案内に沿って連携を有効にします。調査対象のページをブラウザーからノートとして保存し、Joplinで開いて、何を確認する資料なのか自分の短いメモを添えます。まず公開ページ1件だけで試し、保存したノートを開いて本文が読めるか、出典を特定できる情報が残っているかを確認します。公式手順に基づく想定例で、実機確認は未実施です。

Why Today

なぜ今日はこれ？

調査の根拠をタブやブックマークだけで管理すると、記事を書く段階で資料を探し直すことがあります。Joplin Web Clipperなら、閲覧中のページをノートとして取り込み、調査メモと同じ場所に整理できます。

Cautions & FAQ

注意点・FAQ

Web Clipper拡張機能とJoplinデスクトップアプリは、デスクトップアプリが起動するサービスを介して連携します。ファイアウォールやプロキシ設定でサービスに接続できない場合があります。同期を有効にすると選択した同期先へノートが送られるため、社内限定資料を保存する前に同期先と情報管理ルールを確認してください。

Web Clipperを使うのにJoplinデスクトップアプリは必要ですか？

はい。公式手順ではデスクトップアプリの設定画面でWeb Clipperを準備し、アプリが起動するサービスを通してブラウザー拡張機能と連携します。

保存したノートを別の端末と同期するにはJoplin Cloudが必須ですか？

必須ではありません。同期設定はWeb Clipperとは別で、公式ガイドにはJoplin CloudのほかNextcloud、Dropbox、OneDrive、WebDAV、S3、ローカルファイルシステムなどが掲載されています。Joplin Cloudは別料金のプランです。
