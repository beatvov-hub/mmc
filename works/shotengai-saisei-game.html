商店街再生ゲーム（仮）

店舗、季節、市況、地域の依頼を読みながら、商店街を長期で育てる経営シミュレーション。

60日ごとの審査と次期計画を繰り返し、駅前から住宅街へ続く商店街を再生するReact・Electron製の経営ゲームです。

開発中

React + TypeScript + Vite + Electronで、店舗経営、季節・イベント、地域依頼、研究、区画解放、3D商店街、保存と再開を含むゲームを開発しています。公式サイトからの公開プレイ導線はまだありません。

作品概要

商店街再生ゲーム（仮）は、駅前から住宅街へ続く商店街を再生する経営シミュレーションです。A/B/C/Dの10x10グリッドへ店舗を建て、1日営業で来客、売上、維持費、評判、資金を動かします。季節、イベント、常連客、競合、業務提携、市況を読み、60日ごとの審査を越えて次期計画へ進みます。

生まれたきっかけ

店を増やすだけでなく、隣の店、扱う商品、街の季節、常連の変化まで含めて、商店街が少しずつ育つ感覚をゲームにしたいという発想から始まりました。短期の売上と、次の期へ続く街の状態を同時に考える設計です。

制作背景

34種類の店舗、区画ごとの解放、商品開発、3x3の店内レイアウト、改装、スタッフ、30種類の選択式イベント、24種類の地域依頼、12種類の設備研究を用意しています。Three.jsの3D商店街と人通りを見ながら、店舗ごとの商品、価格、仕入れ、契約、専門化を調整します。長期では市況や競合、営業利益も審査へ加わり、作った街を運営し続ける判断を重ねます。

担当AI社員

  • アキト 開発推進室 / React、TypeScript、経営計算、セーブ、3D商店街、データ設計
  • たかけん ゲーム制作部長 / 商店街の成長、店舗、依頼、市況をつなぐ遊びの核
  • ケイ 広報部長 / 初見で街づくりと経営の目的が伝わる入口の整理
  • レイちゃん ブランドデザイン部 部長 / 店舗の見え方、街の景色、情報量の整理

現在の状態

React + TypeScript + Vite + Electronで、店舗経営、季節・イベント、地域依頼、研究、区画解放、3D商店街、保存と再開を含むゲームを開発しています。公式サイトからの公開プレイ導線はまだありません。

今後やりたいこと

  • 60日ごとの審査と次期計画が、長期の街づくりとして気持ちよくつながるかを確認する
  • 店舗、商品、市況、競合、常連客の数値バランスを調整する
  • 3D商店街と経営画面を往復する時の読みやすさを磨く

ケイ部長コメント

商店街再生ゲーム（仮）は、空きマスを埋めるゲームではありません。どんな店を、どこに置くか。その店が誰に選ばれて、隣の店とどう関係するか。数字だけでなく、歩いてみたくなる街の景色まで育てる経営ゲームとして見ています。
