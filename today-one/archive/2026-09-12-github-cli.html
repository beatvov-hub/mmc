GitHub CLI

一言でいうと

GitHubのIssue、プルリクエスト、Actionsなどを、コードを置いたターミナルから確認・操作する公式コマンドラインツールです。

公式サイトを見る ↗（外部サイト）

Why Today

なぜ今日はこれ？

AIへ実装を頼む前に、何を直すのかがIssue本文とずれていれば、コードだけ整っても仕事は終わりません。GitHub CLIならリポジトリの近くで未完了の課題を取り出せるため、今日着手する1件と完了条件を先にそろえられます。

Use For

何に使える？

例えば、サイト改修で残っている確認を朝に整理する場面に。GitHub CLIを導入し、対象リポジトリで「gh issue list --state open --limit 10 --json number,title,labels,updatedAt,url」を実行します。出力から今日見る1件を人が選び、本文と関連するプルリクエストをWebで読んで、次の作業と完了条件をメモにします。成果物は、URL付きの着手候補と完了条件です。最初は一覧取得だけで始め、Issueの作成・編集・クローズは権限と公開範囲を確認してから行います。
