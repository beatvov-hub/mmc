Ruff

For Whom

こんな人向け

Pythonの小さなスクリプトを共有・レビューする前に、未使用のimportや基本的な書き方の問題を先に見つけたい開発担当者向けです。

The Answer

結論

RuffはPythonのコードを検査し、未使用の読み込みなどのミスや書式の乱れを見つけるツールです。

How to Use

やり方／確認方法

例えば、社内の集計用Pythonスクリプトを共有する前に確認する想定例です。Pythonプロジェクトとuvを用意し、公式手順で開発用依存にRuffを追加したうえで、対象ファイルにuv run ruff check path/to/script.pyを実行します。出力には該当行とルールが示され、未使用のimportなどを確認できます。まず1ファイルだけを対象にし、指摘が意図した問題か見てから、必要なら--fixで自動修正し差分を確認します。この例は未実施です。

Why Today

なぜ今日はこれ？

小さなPythonスクリプトでも、使っていない読み込みや基本的な書き方の揺れはレビュー時に埋もれがちです。Ruffは既定の検査ルールでファイルを確認し、問題の場所と内容を一覧にできるため、共有前の確認を始めやすくします。

Cautions & FAQ

注意点・FAQ

Ruffの既定ルールで見つけられる範囲の指摘であり、プログラムの仕様や処理結果が正しいことを保証するものではありません。`--fix`を付けると修正可能な箇所を変更するため、差分を確認してください。

設定ファイルを用意しないと使えませんか？

いいえ。Ruffの公式チュートリアルでは既定の設定で検査を始めており、標準では一般的なミスなどに関するルールが有効です。必要に応じて後からプロジェクト設定で調整できます。

検査を実行するとファイルは自動で書き換わりますか？

通常のruff checkは指摘を表示します。自動修正はruff check --fixを使った場合に行われ、整形は別コマンドのruff formatで実行します。
