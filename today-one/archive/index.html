Power Automate for desktop

Power Automate for desktopは、Windows上のアプリやWeb画面の繰り返し操作を記録し、再実行できるデスクトップ自動化ツールです。

こんな場面に
例えば、週次イベントの案内表から社内CMSの下書き欄へ開催名・日時・会場を写す想定例です。
向いている人
定例イベントの情報をWebフォームやCMSへ繰り返し入力し、転記ミスを減らしたい総務・運営・広報担当者向けです。
導入前に
Web画面の入力欄や構造が変わると、フローが対象要素を見つけられず停止することがあります。実データで試す前にテスト画面とダミー情報で入力先・停止位置を確かめ、送信・公開ボタンはフローに含めず担当者が確定する運用がおすすめです。

推薦：ほのちゃん　情報確認：2026-11-09

Scribus

Scribusは、文字と画像をページ上に配置し、印刷向けの塗り足し付きPDFを書き出せる無料のDTPソフトです。

こんな場面に
例えば、イベント告知のA5チラシを印刷会社へ渡す想定例です。
向いている人
イベントや広報用の紙チラシを作り、印刷所の寸法・塗り足し仕様に合わせてPDFを入稿したい担当者向けです。
導入前に
塗り足しの量やPDFの色・規格は印刷所や印刷物ごとに指定が異なります。書き出し設定を一律に決めず、入稿先へ確認してください。書体・写真素材の利用範囲も素材ごとに確かめます。

Openverse

Openverseは、Web上のオープンライセンス画像を検索し、個別の利用条件を確認して素材候補を探せる無料サービスです。

こんな場面に
例えば、記事のアイキャッチ用画像を探す想定例です。
向いている人
記事のアイキャッチ画像が必要で、作者・利用条件・出典元を確かめてから公開したい編集・広報担当者向けです。
導入前に
Openverseは第三者サイトの作品情報を集めた検索サービスで、ライセンス表示の正確さを保証していません。検索結果だけで判断せず元サイトの作品ページでも条件を確かめ、必要な作者表示を残してください。

推薦：コトちゃん　情報確認：2026-11-07

draw.io Desktop

draw.io Desktopは、CSVの各行を図形にして、業務フローなどの図を作れる無料の図解ツールです。

こんな場面に
例えば、イベント受付で担当が交代する流れを見える化する想定例です。
向いている人
イベント受付や社内案内など、工程の順番と担当交代を表だけでは伝えにくい運営・総務担当者向けです。
導入前に
CSVの行から図を作るには、図形のラベルや接続に使う書式指定も必要です。最初は個人情報を含めない数行のCSVで試し、取り込み後に工程名と矢印の向きを元表と照合してください。

Subtitle Edit

Subtitle Editは、動画に合わせて字幕の文章や表示時刻を調整し、SRTなどの字幕ファイルとして保存できる無料の編集ツールです。

こんな場面に
例えば、告知動画全体で字幕が一律に遅れている場合の想定例です。
向いている人
告知動画にSRT字幕を付けていて、字幕全体の表示が音声より早い・遅い問題を直したい広報・動画担当者向けです。
導入前に
全体の時刻調整は、動画の途中からずれ方が変わるケースには合わない場合があります。また、時刻の修正は字幕文の正しさを保証せず、字幕を動画へ焼き込む作業も別です。

推薦：ケイ　情報確認：2026-11-05

ImageMagick

ImageMagickは、複数の画像をタイル状に並べ、比較用シート1枚にまとめる無料の画像処理ツールです。

こんな場面に
例えば、TシャツのSNS告知用デザイン案6枚から候補を絞る想定例です。
向いている人
TシャツやSNS画像のデザイン案を複数作り、配色や余白を並べて比べたい制作・広報担当者向けです。
導入前に
比較シートでは元画像が縮小されるため、小さな文字や線の細部は見えにくくなります。候補を絞る用途に使い、公開前の仕上がりは元画像を原寸で確認してください。

CyberChef

CyberChefは、ブラウザ上で文字列やファイルの変換・解析を組み合わせ、入力の意味を確かめられる無料のオープンソースツールです。

こんな場面に
想定例：告知URLに含まれるutm_campaignの日本語表記を読み取り、登録名と照合したい場合です。
向いている人
告知リンクやキャンペーンURLの長いパラメーターを読み取り、表記を照合したい広報・企画担当者向けです。
導入前に
URL Decodeは%エンコードを戻す処理で、計測設定やリンク先の安全性は判定しません。公式Webアプリの共有URLには入力やレシピを含められるため、秘密情報を入力・共有しないでください。

HandBrake

HandBrakeは、手元の動画を別の形式へ変換し、画質とファイル容量のバランスを調整できる無料の動画変換ソフトです。

こんな場面に
活用例：告知動画を掲載先の容量上限に合わせたい広報担当向けです。
向いている人
告知動画のファイル容量を調整したい広報・動画制作担当者向けです。
導入前に
画質を下げると容量は小さくなる傾向がありますが、細部や文字の見え方も変わります。短いプレビューの後、完成した動画を全編再生して確認してください。

Sweet Home 3D

Sweet Home 3Dは、部屋の壁や家具を2D平面図に配置し、同じレイアウトを3Dで見比べながら案を作れる無料デスクトップアプリです。

こんな場面に
例えば、交流会を開く部屋の机と椅子の配置を事前に比べる想定例です。
向いている人
交流会や小規模イベントの設営前に、机の配置や通路の見え方を関係者と共有したい会場・広報担当者向けです。
導入前に
図面画像の縮尺と家具寸法は実測と照合してください。3D表示は配置を検討するためのプレビューで、建築・避難経路の適合を保証しません。公開資料では追加した家具モデルやテクスチャのライセンス・作者表示も確認してください。

推薦：レイちゃん　情報確認：2026-11-01

lychee

lycheeは、MarkdownやHTMLに書かれたリンクをたどり、リンク先の応答を一覧で確かめるツールです。

こんな場面に
例えば、公開前のお知らせ原稿に古いリンクが残っていないか確認する想定例です。
向いている人
告知文や案内記事を公開する前に、本文中のリンクが読者から開けるか確認したい編集・広報担当者向けです。
導入前に
相手サイトの一時的な応答制限やアクセス拒否で、リンクが失敗と判定されることがあります。結果だけでリンクを削除せず、該当先を開いて確認してください。

ripgrep

ripgrepは、指定したフォルダー内の文章やコードから語句を探し、見つかった行をファイル名と行番号付きで表示する検索ツールです。

こんな場面に
例えば、既存リポジトリのscriptsフォルダーに残るTODOとFIXMEを棚卸しする想定例です。
向いている人
既存コードを引き継ぎ、TODOやFIXMEがどこに残っているか先に把握したい開発・保守担当者向けです。
導入前に
標準ではgitignore対象、隠しファイル、バイナリファイルなどを検索しません。結果は検索語がある行の一覧で、対応の要否や作業完了を判定するものではありません。

推薦：アキト　情報確認：2026-10-30

Marp CLI

Marp CLIは、Markdownで書いた原稿をブラウザーで確認できるスライドやPDF、PowerPointに変換するコマンドラインツールです。

こんな場面に
例えば、公開済みのお知らせを3枚の説明スライドにする想定例です。
向いている人
社内のお知らせや企画メモをスライドにまとめる際、原稿の修正と配布版の更新を揃えたい広報・デザイン担当者向けです。
導入前に
Marpは画面上で自由に編集する一般的なプレゼンソフトとは異なり、Markdownの原稿をスライドへ変換します。PDF・PowerPoint・画像出力には対応ブラウザーが必要です。
