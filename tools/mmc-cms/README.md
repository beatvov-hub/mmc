# MMC 更新室（ローカルCMS）

毎日見る株式会社の静的サイトを、手元の画面から安全に更新するためのローカルCMSです。

- 外部AI API・有料APIは使用しません。
- 既存の `loungeLogs.json`、AI鑑識室の記事JSON、Python生成スクリプトをそのまま利用します。
- GitコミットやNetlifyへの公開は行いません。
- サーバーは `127.0.0.1` だけで待ち受けます。

## 起動方法

リポジトリ直下の `start-cms.cmd` をダブルクリックしてください。

1. 黒い画面が開き、ローカルサーバーが起動します。
2. ブラウザーで `http://127.0.0.1:4310/` が自動的に開きます。
3. 終了するときは黒い画面で `Ctrl+C` を押すか、画面を閉じます。

Node.js 18以上が必要です。追加パッケージのインストールは不要です。

## MMCラウンジの更新

1. 「MMCラウンジ」を開き、Markdown風の原稿を貼り付けます。
2. 「原稿を解析」を押します。
3. 日付・時刻・曜日・時間帯・タイトル・参加者を確認します。
4. 構造化プレビューで、情景文・会話・注釈・引用・今日の一言を修正します。
   - ブロックは上下移動、削除、追加できます。
   - 会話内の発言者、文章、文章種別も変更できます。
   - 「所長」は通常の発言者として指定できます。既存生成処理側でアイコンなしの表示になります。
5. 「入力チェック」を押します。
6. 「保存されるJSON」を確認し、「ラウンジを生成」を押します。

生成時は次の処理が行われます。

1. `src/data/loungeLogs.json` を一時ファイルへ書き、JSONとして再検証します。
2. 更新前のデータと生成対象を `tools/mmc-cms/backups/` に保存します。
3. 安全に元データを置き換えます。
4. 既存の `scripts/generate_lounge.py` を実行します。
5. `lounge.html`、`index.html`、日別アーカイブ、カレンダー、サイトマップを更新します。

同じIDがある場合、上書き確認欄が表示されます。確認欄をチェックしない限り上書きしません。

## AI鑑識室の更新

1. 「AI鑑識室」を開きます。
2. 記事JSONを貼り付けて「JSONをフォームへ反映」を押すか、「新規フォーム」から入力します。
3. 基本情報、シナリオ、質問、確認ポイント、判定、安全な行動、情報源などを確認します。
4. `image/ai-forensics/` の画像一覧から記事画像を選びます。
5. 「入力チェック」を押します。
6. 「保存されるJSON」を確認し、「記事を生成」を押します。

以下を保存前に検証します。

- JSON構文
- 既存生成処理が必要とする必須項目
- `case-YYYYMMDD` / `case-YYYYMMDD-02` 形式のIDと公開日の整合
- カテゴリ、難易度、確認レベル
- 質問の選択肢IDと `recommendedAnswers`
- 確認ポイント、行動、情報源などの構造
- `http` / `https` の情報源URL
- 記事画像が `image/ai-forensics/` 内に実在すること
- 重複ID

壊れたMarkdownリンクや不可視文字を検出した場合は修正候補を表示します。候補は自動適用されません。内容を見てチェックしたものだけ適用してください。

生成時は記事JSONを `src/data/ai-forensics/<ID>.json` へ保存し、次の順に既存処理を実行します。

1. `scripts/generate_ai_forensics.py`
2. `scripts/generate_lounge.py`（サイトマップ反映）

## Python設定

起動時に次の順でPython 3を探します。

1. CMS設定で指定した `python.exe`
2. `PATH` 上の `python` / `python3`
3. Windows Python Launcher
4. `%USERPROFILE%\.cache\codex-runtimes\` 内のCodex同梱Python

自動検出できない場合は「設定・復元」で `python.exe` の絶対パスを指定してください。任意のコマンドや引数は指定できません。

## バックアップと復元

CMSで生成するたびに、更新前の元データと生成対象を `tools/mmc-cms/backups/` へ保存します。このフォルダーはGit管理対象外です。

「設定・復元」から「前回の更新を元に戻す」を実行できます。

- CMSが最後に正常完了した1回分が対象です。
- 更新後に対象ファイルが手動変更されている場合、上書きせず競合ファイルを表示して停止します。
- 生成中にエラーが起きた場合は、その場で更新前のファイルへ戻します。

## テスト

PowerShellでこのフォルダーへ移動し、次を実行します。

```powershell
node --test
```

または、PowerShellの実行ポリシーで `npm.ps1` が許可されている環境では次でも実行できます。

```powershell
npm test
```

テスト対象は、ラウンジ原稿パーサー、記事/ラウンジ検証、URL修正候補、一時ファイル保存、バックアップ復元、競合時の停止、リポジトリ外パスの拒否です。

## ファイル構成

```text
tools/mmc-cms/
├─ public/              管理画面
├─ lib/                 パーサー、検証、保存、Python実行
├─ test/                Node.js標準テスト
├─ backups/             更新前バックアップ（Git管理外）
├─ server.js            ローカルサーバー
├─ start-cms.cmd        このフォルダーからの起動用
└─ package.json
```

## 現在の制約

- Markdown風原稿の解析はルールベースです。自由度の高い原稿は、構造化プレビューで手直ししてください。
- 画像の新規アップロードや編集は行いません。先に `image/ai-forensics/` へ画像を置いてから選択します。
- 公開、Gitコミット、Netlifyデプロイは別途手動で行ってください。
- 同時に複数のCMS画面から更新する運用は想定していません。
