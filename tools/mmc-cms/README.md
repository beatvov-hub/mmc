# MMC Workline

毎日見る株式会社の業務進行・更新管理ツールです。

これまでのローカルCMS「MMC 更新室」は、MMC Workline内の「サイト更新室」として残しています。ラウンジ更新、AI鑑識室更新、バックアップ、復元、既存のPython生成スクリプトは引き続き利用できます。

## 起動

リポジトリ直下のどちらかをダブルクリックしてください。

```text
start-workline.cmd
start-cms.cmd
```

`start-cms.cmd` は互換性のため残しています。どちらも同じMMC Worklineを起動します。

ブラウザーでは次のURLを開きます。

```text
http://127.0.0.1:4310/
```

## 方針

- 外部AI API・有料APIは使いません。
- サーバーは `127.0.0.1` のみで待ち受けます。
- GitコミットやNetlify公開は自動実行しません。
- 既存のJSONデータとPython生成スクリプトを利用します。
- 更新前バックアップを残します。
- リポジトリ外のファイル操作は拒否します。
- Node.js 18以上で動作します。

## 主な機能

### ダッシュボード

進行中、確認待ち、Codex作業中、今月完了の件数を確認できます。期限が近いタスク、最近の活動、最近生成したサイトコンテンツも表示します。

### 進行ボード

MMC専用ステータスでタスクを管理します。

- 構想中
- 相談中
- 仕様整理中
- Codex依頼待ち
- Codex作業中
- 確認待ち
- 修正中
- 公開準備中
- 完了
- 保留

カード上の状態メニューからステータスを変更できます。

### タイムライン

開始日と終了日があるタスクをガントチャート風に表示します。期間未設定タスクは別枠に表示します。

### サイト更新室

既存の更新機能です。

- MMCラウンジ原稿の解析、構造化、生成
- AI鑑識室JSONの読み込み、検証、生成
- 更新前バックアップ
- 前回更新の復元
- 任意の関連タスク紐付け

生成に成功すると、活動履歴と成果物に記録されます。

### 成果物

記事、画像、ドキュメント、コード、Webサイト、データなどを手動登録できます。サイト更新室で生成した記事も成果物として記録されます。

### 業務振り返り

完了したタスクに対して、AI・ツール活用を含む業務上の学びを記録できます。AI社員の採点やランキングではなく、次回の指示方法、確認方法、成果物の再利用可否を判断するためのメモです。

- タスク本体とは別の `workline-evaluations.json` に保存します。
- 1つのタスクへ複数回の振り返りを残せます。
- 「未評価」「後で評価」「評価済み」「評価対象外」を区別します。
- 実行主体、人間の修正量、採否、再利用性、次回変えることを残せます。
- 会話全文、プロンプト全文、認証情報、機密資料本文は保存しません。

### 社員・部署

Workline内で使う担当社員と部署を管理できます。初回起動時には、毎日見る株式会社のAI社員・社外協力者が初期データとして登録されます。

## データ保存

Worklineのデータは以下へ保存されます。

```text
tools/mmc-cms/data/
├─ workline-tasks.json
├─ workline-links.json
├─ workline-artifacts.json
├─ workline-evaluations.json
├─ workline-employees.json
├─ workline-departments.json
├─ workline-activity.json
└─ workline-settings.json
```

保存時は一時ファイルへ書き込み、JSONとして再検証してから置き換えます。保存前のデータは `tools/mmc-cms/data/backups/` に退避します。

## テスト

このフォルダーで次を実行します。

```powershell
node --test
```

## 現在の制限

- ドラッグ＆ドロップでのステータス変更は未実装です。カード内の状態メニューで変更します。
- ローカルファイルやフォルダは、危険な直接実行を避け、パス登録とコピーを中心に扱います。
- スマートフォン対応より、Windowsデスクトップブラウザーでの日常利用を優先しています。
