# オフィスの標準吹き出し

2026-09-13更新。各12種類、社員11名＋社外協力者ペチの計144種類。

参照元は[共有Driveの社員プロフィール](https://drive.google.com/drive/u/0/folders/13R6ivrW3HeEQExX4iPIK-sqRp2xh0QXK)内の各人の「話し方・口癖」「趣味・好きなこと」「日常の癖」など。原文をそのまま収録するのではなく、オフィス用の短い創作セリフにしています。実際の作業完了・調査結果・現在の健康状態などを報告する機能ではありません。

- ほのちゃん：穏やかな総務、優先順位整理、コーヒー、さりげない休憩の声掛け。
- ショウマ：軽快な企画営業口調、シリーズ化、読者・商品目線、カフェラテとプリン。
- マイケル：落ち着いた海外文化比較、翻訳の温度感、地図旅行、オンライン取材。
- たかけん：静かなゲーム企画熱、運命・供物、紙の試作、焚き火。
- DG：関西弁の人狼文化観測、別視点・GM、地理やブラックコーヒーの小ネタ。
- レイちゃん：明るいデザイン談義、ブランドの統一感、余白、紙袋や焼き菓子。
- アキト：冷静な要件・構造整理、小さな検証、README、机の配線と猫動画。
- ケイ：関西弁の広報、初見の読者、サイトの伝わりやすさ、照明と名言Tシャツ。
- ねむちゃん：ゆっくり眠そうな人事口調、既存社員の強み、ココアと文房具。
- 誠：丁寧な根拠確認、断定を急がない姿勢、無糖紅茶とプリンの淡々とした冗談。
- コトちゃん：親しみのある編集口調、体験と言葉の芯、赤ペン・本の帯・お好み焼き。
- ペチ：犬語だけにせず丁寧な寸評、ライバル心、クッションと「協議中」の茶目っ気。

候補は `lib/office-state.js` の `DEFAULT_OFFICE_LINES` に定義しています。社員詳細に手動登録された `officeLines` があれば、従来どおりそちらを優先します。標準候補を利用するには社員詳細の吹き出し欄を空にします。社員マスタ・タスク・活動履歴は今回の変更では書き換えません。

単体版へ反映するには再ビルドし、起動中のWorklineを終了して新しいEXEで起動してください。
